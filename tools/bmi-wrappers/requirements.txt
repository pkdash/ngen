# Python BMI wrapper packages, installed into .venv-linux for introspection only.
# ngen itself still runs these models through its C/Fortran BMI adapters; nothing
# here is imported by the ngen binary.
#
# Each of these is a compiled extension that links the model's BMI shared library
# at build time, so the corresponding lib_file in wrappers.json must exist before
# pip runs. `make -C commands install-bmi-wrappers` enforces that ordering.
